# BasedItemEsp

Production Anti Item-ESP for Paper 1.20.4+ using ProtocolLib.

## Requirements
- Paper 1.20.4+
- ProtocolLib 5.1.0+
- Java 17+

## Build
```bash
cd BasedItemEsp
mvn -q package
```
Jar: `target/BasedItemEsp.jar`

## Permission
- `itemesp.bypass` (default: op) — see all items regardless of LOS

## Config
See `src/main/resources/config.yml`
